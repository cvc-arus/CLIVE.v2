- 2026-10-08: fixed the mock's two open query-handling defects. New `services/simpro_mock/simpro_mock/ordering.py` implements **`orderby`** on all 13 collection routes — a csv list of wire column names with a `-` prefix for descending, resolved through the same `FILTER_MAPS` the filters use, because the orderable set is the scalar columns.
